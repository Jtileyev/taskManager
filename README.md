# Task Manager Auth Module

Простое PHP-приложение для авторизации и регистрации пользователей с использованием MariaDB.

## Возможности
- Блокировка доступа с мобильных устройств с отображением отдельной страницы.
- Регистрация пользователей с полями ФИО, почта и телефон. Роль назначается автоматически как «Пользователь».
- Авторизация с последующим перенаправлением на главную страницу.
- Отображение подтверждения успешной авторизации.
- Структура MVC с контроллерами, моделями и представлениями.
- Поддержка ЧПУ-адресов (`/register`, `/login`, `/dashboard`).
- Использование Bootstrap 5 и фирменной палитры (#2B4070, #6FC9EC).

## Требования
- PHP 8.1+
- MariaDB 10+
- Composer не требуется

## Установка
1. Склонируйте репозиторий и перейдите в директорию проекта.
2. Создайте базу данных и таблицы, выполнив скрипт `database.sql` в MariaDB.
3. Настройте подключение к базе в файле `config.php` (логин и пароль пользователя БД).
4. Разместите проект в корневой директории веб-сервера или запустите встроенный сервер PHP:
   ```bash
   php -S 0.0.0.0:8000
   ```
5. Перейдите по адресу `http://localhost:8000/` в настольном браузере.

## Структура
- `index.php` — фронт-контроллер и маршрутизатор.
- `app/Core` — базовые компоненты (роутер, контроллер, сессия, подключение к БД).
- `app/Controllers` — контроллеры приложения.
- `app/Models` — модели домена (например, `User`).
- `app/Views` — представления для авторизации и дашборда.
- `app/Support/helpers.php` — вспомогательные функции и старт сессии.
- `styles.css` — пользовательские стили с фирменной палитрой.
- `database.sql` — SQL-скрипт для создания базы данных и таблиц.

## Дополнительно
- Пароли хранятся в виде хэшей `password_hash`.
- Для визуального оформления используется CDN Bootstrap 5.
- Для поддержки ЧПУ добавлен `.htaccess` с перенаправлением всех запросов на `index.php`.
